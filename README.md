# Psychic-Sleuth

Build a sleek, dark-themed AI Mystery Game web app inspired by The Mentalist.

​Theme: Dark navy, charcoal, and warm amber accents with a sophisticated detective agency aesthetic.

​Layout:

​Sidebar Navigation: Dashboard (Cases), Active Case, Evidence Board, Suspect List, Profile.

​Main Screen (Interrogation View):

​Left Panel: Suspect dossier showing photo, bio, alibi, relationship to victim, and a dynamic 'Stress Level' progress bar.

​Center Panel: Chat interface with custom stylized speech bubbles for interrogating the AI suspect. Include an input field and a 'Press the Suspect' toggle button.

​Right Panel: Interactive Evidence Drawer listing discovered clues. Clicking a clue appends it to the chat input to confront the suspect.

​Top Bar: Case timer, remaining 'Jane Intuition' hint tokens, and a prominent 'Accuse Suspect' call-to-action button.

​Include mock data for one case: 'The Enigma at Blackwood Manor' with 3 suspects (The Business Partner, The Ex-Spouse, The Butler).
